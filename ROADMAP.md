# Roadmap

What we're working on with QR, in order and without dates, as the
[Robin's Code](https://honestrobin.com/code) asks. Plans aren't promises; the Code is. Everything
you'd notice is in [`CHANGELOG.md`](CHANGELOG.md) when it ships.

## Now

The free tool, as it is, made a joy to use before anything is added to it. The maintainer uses it
for real codes, and says when it's there.

## Next

Guides next to the tool, each with the tool one click away: how big a QR code has to be for its
link; why some QR codes stop working, and how to make one that doesn't; and which colours scan.
English first, then every language, checked back like the page's own words.

## Later

**Codes you can change after printing, with scan counts.** A paid option, for anyone who needs a
printed code to point somewhere new later. Such a code would go through an address instead of
holding the link itself: your own address (one DNS record, no lock-in), a short link of ours, or
the same software on your own server, free. Scan counts say how many, when and roughly where,
never who. Leaving keeps every printed code working.

**One Honest Robin account for every tool.** The paid option would be its first use.

Everything in the free tool stays free and complete. The paid option adds a service we run; it
takes nothing away from the page you use today.
