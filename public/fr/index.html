Questions

Le code expire-t-il ?

Non. Le code contient votre lien tel quel et l’ouvre directement, sans passer par nous. Il fonctionne tant que votre lien fonctionne, et il ne dépend pas du tout de nous.

Quelle est la taille minimale pour l’imprimer ?

Cela dépend du code. Un lien plus long donne un code avec plus de carrés, et chaque carré a besoin d’environ 0,6 mm pour qu’un téléphone le lise. Sous les boutons, la page indique la taille minimale de votre code. Elle n’est jamais inférieure à 2 cm.

PNG ou SVG ?

Les deux contiennent le même code. Le PNG fonctionne dans toutes les applications. Le SVG reste net à toutes les tailles : utilisez-le pour tout ce que vous imprimez.

Puis-je changer le lien plus tard ?

Non. Le lien fait partie du code : un code imprimé ne peut pas changer, et nous ne pouvons pas le désactiver. Si vous pensez devoir un jour changer sa destination, faites-le pointer vers une page de votre propre site, et modifiez cette page.

Voyez-vous ce que je tape ?

Non. Votre code est créé sur votre propre appareil, et rien de ce que vous tapez n’est envoyé nulle part. Nous comptons les visites et ce qui se fait sur la page, comme le nombre de codes créés, jamais leur contenu. Le code source de cette page est public : tout le monde peut vérifier.

Pourquoi est-ce gratuit ?

Cela ne nous coûte presque rien : c’est votre appareil qui crée le code, pas nos serveurs. Et c’est une façon de découvrir Honest Robin, qui fait aussi des logiciels pour le travail.
