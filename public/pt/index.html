Perguntas

O código expira?

Não. O código guarda o seu link dentro dele e o abre diretamente, sem passar por nós. Ele funciona enquanto o seu link funcionar e não depende de nós em nada.

Qual o menor tamanho para imprimir?

Depende do código. Um link mais longo gera um código com mais quadradinhos, e cada um precisa de uns 0,6 mm para o celular ler. Abaixo dos botões, a página mostra o menor tamanho para o seu código. Nunca é menos de 2 cm.

PNG ou SVG?

Os dois têm o mesmo código. O PNG funciona em qualquer aplicativo. O SVG fica nítido em qualquer tamanho, então use-o para tudo o que for imprimir.

Posso mudar o link depois?

Não. O link faz parte do código, então um código impresso não pode mudar, e nós não podemos desativá-lo. Se achar que um dia vai precisar mudar para onde ele leva, aponte-o para uma página do seu próprio site e mude essa página. Uma opção paga, com códigos que você pode mudar depois de imprimir e com contagem de leituras, está nos nossos planos. A ferramenta gratuita continua gratuita, com tudo o que tem.

Vocês veem o que eu digito?

Não. O seu código é criado no seu próprio aparelho, e nada do que você digita é enviado para lugar nenhum. Contamos as visitas e o que é feito na página, como quantos códigos são criados, nunca o que há neles. O código-fonte desta página é público, então qualquer pessoa pode conferir.

Como pode ser grátis?

Quase não nos custa nada mantê-lo: quem cria o código é o seu aparelho, não os nossos servidores. E é um jeito de as pessoas conhecerem a Honest Robin, que também faz software para o trabalho.
