Preguntas

¿El código caduca?

No. El código lleva tu enlace dentro y lo abre directamente, sin pasar por nosotros. Funciona mientras funcione tu enlace y no depende de nosotros para nada.

¿Cuál es el tamaño mínimo para imprimirlo?

Depende del código. Un enlace más largo da un código con más cuadrados, y cada cuadrado necesita unos 0,6 mm para que un teléfono lo lea. Debajo de los botones, la página indica el tamaño mínimo de tu código. Nunca es menos de 2 cm.

¿PNG o SVG?

Los dos llevan el mismo código. PNG funciona en cualquier aplicación. SVG se ve nítido a cualquier tamaño, así que úsalo para todo lo que imprimas.

¿Puedo cambiar el enlace más adelante?

No. El enlace forma parte del código, así que un código impreso no puede cambiar y nosotros no podemos desactivarlo. Si es posible que necesites cambiar adónde lleva, haz que apunte a una página de tu propio sitio web y cambia esa página. Una opción de pago con códigos que puedes cambiar después de imprimirlos, y con recuento de escaneos, está en nuestros planes. La herramienta gratuita sigue siendo gratuita, con todo lo que tiene.

¿Honest Robin ve lo que escribo?

No. Tu código se crea en tu propio dispositivo, y nada de lo que escribes se envía a ningún sitio. Contamos las visitas y lo que se hace en la página, como cuántos códigos se crean, nunca lo que contienen. El código fuente de esta página es público, así que cualquiera puede comprobarlo.

¿Cómo puede ser gratis?

Casi no nos cuesta nada mantenerlo: el código lo crea tu dispositivo, no nuestros servidores. Y es una forma de conocer Honest Robin, que también hace software para el trabajo.
