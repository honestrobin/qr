Questions

Does the code expire?

No. The code holds your link itself and opens it directly, not through us. It works for as long as your link does, and it doesn’t depend on us at all.

How small can I print it?

That depends on the code. A longer link makes a code with more squares, and each square needs about 0.6 mm for a phone to read it. Under the buttons, the page says the smallest size for your code. It’s never less than 2 cm (0.8 in).

PNG or SVG?

Both hold the same code. PNG works in every app. SVG stays sharp at any size, so use it for anything you print.

Can I change the link later?

No. The link is part of the code, so a printed code can’t change, and we can’t switch it off. If you may need to change where it leads, point it at a page on your own website, and change that page.

Do you see what I type?

No. Your code is made on your own device, and nothing you type is sent anywhere. We count visits and what’s done on the page, such as how many codes are made, never what’s in them. This page’s source code is public, so anyone can check.

How is it free?

It costs us almost nothing to run: your device makes the code, not our servers. And it’s a way for people to meet Honest Robin, which also makes software for work.
