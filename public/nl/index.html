Vragen

Verloopt de code?

Nee. De code bevat je link zelf en opent hem rechtstreeks, niet via ons. Hij werkt zolang je link werkt, en hij hangt helemaal niet van ons af.

Hoe klein kan ik hem afdrukken?

Dat hangt van de code af. Een langere link geeft een code met meer vakjes, en elk vakje heeft ongeveer 0,6 mm nodig zodat een telefoon het kan lezen. Onder de knoppen staat de kleinste maat voor jouw code. Die is nooit kleiner dan 2 cm.

PNG of SVG?

Beide bevatten dezelfde code. PNG werkt in elke app. SVG blijft scherp op elk formaat, dus gebruik het voor alles wat je afdrukt.

Kan ik de link later wijzigen?

Nee. De link is onderdeel van de code, dus een afgedrukte code kan niet veranderen, en wij kunnen hem niet uitzetten. Moet je misschien later wijzigen waar hij heen gaat, laat hem dan naar een pagina op je eigen website wijzen en pas die pagina aan.

Zien jullie wat ik typ?

Nee. Je code wordt op je eigen apparaat gemaakt, en niets van wat je typt wordt ergens naartoe gestuurd. We tellen bezoeken en wat er op de pagina gebeurt, zoals hoeveel codes er worden gemaakt, maar nooit wat erin staat. De broncode van deze pagina is openbaar, dus iedereen kan het controleren.

Hoe kan het gratis zijn?

Het kost ons bijna niets: je apparaat maakt de code, niet onze servers. En zo leren mensen Honest Robin kennen, dat ook software voor het werk maakt.
