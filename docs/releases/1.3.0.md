# QR 1.3.0, 11 October 2026

## What changed

- **The print size.** The PNG was 1024 pixels wide with no size in it, so documents and printers
  guessed about 27 cm, a full page; the SVG said about 9 cm. The size is now chosen under the code
  (5 cm unless chosen otherwise, never under the size that scans, at most 50 cm), and both files
  carry it: the PNG in a pHYs chunk, the SVG in centimetres. The line that said how small you can
  print stays, under it.
- **Print a sheet:** as many copies as fit on one page at that size, A4 or Letter, with the
  sticker's cut lines and an optional caption under each, through the browser's print window
  (which can also save a PDF). The caption is typed and printed here, and sent nowhere.
- **Drop a picture** anywhere on the page to put it in the middle of the code.
- **"Scans fine" sits with the code**, under the print size, apart from the robin's line, so the
  check doesn't read as the robin's wit. The robin's line grows out of its head when it comes and
  shrinks back when it goes.

## Promises this release touches

| Promise | How | Ledger |
|---|---|---|
| The files carry the print size you chose | New | Tested |
| What you type stays on this page | The sheet's caption is typed here too; the privacy test now types what it watches for into it and prints | Tested |
| Checked before you print it: it says how small you can print | Said under the print size now, and hidden while the code doesn't scan | Tested |

**Guards changed:** the tests that read the old line ("print it at least 2 cm wide") and checked
it hides on a failing code now read the new one ("At least 2 cm, so phones can read it") and check
that it hides. The Keep it plain check looks for the robin's row to be gone instead of measuring
its height.

## What the maintainer read

missed, and approved the list and the recommendations.
He saw screenshots and the printed sheet, and gave his go to go live before his own test.
