# QR 1.0.0, 11 October 2026

The first release of Honest Robin: QR, at qr.honestrobin.com.

## What changed

- Make a QR code for a link or any text. It appears as you type, with one line on what it opens.
- When typing stops, the page reads its own code back and says whether it scans, and how small
  you can print it.
- When something looks like a mistake, such as a link without https://, the page suggests the
  fix. Only your tap makes it.
- Colours, a see-through background, and an image in the middle (the robin, or your own, which
  stays in your browser), each with a plain warning when it won't scan.
- Copy, Download PNG and Download SVG; on phones, Save or share.
- In 13 languages, each at its own address. The page follows the language you picked, else your
  browser's, never your IP address.

## Promises this release touches

| Promise | How | Ledger |
|---|---|---|
| What you type stays on this page | New: nothing typed is sent, put in the address or stored | Tested |
| Once loaded, it works offline | New | Tested |
| A code that's yours to keep | New: the code holds what was typed, byte for byte | Tested |
| Never change what someone typed | New: fixes are suggested, applied only by a tap | Tested |
| Every company that touches your data is listed | New: Cloudflare (United States) serves the page and counts page views | Tested |
| By default we only count visits, without cookies | New: Cloudflare's cookie-free counter, added at its edge by honestrobin.com's automatic setup, nothing more | Tested |
| A person is one step away | QR has no way to reach one yet | Not built |
| The code is open source | The licence is the AGPL; the repository is private until it's published | Not built |

The ledger checker passes: `python3 robinscode/harness/ledger.py qr`.

## What agents checked

- CI on the release commit, `eb3d343` (pull request #1, run
  [38097945410](https://github.com/honestrobin/qr/actions/runs/38097945410)), and again before the
  deploy: 214 passed, none failed or flaky. Desktop Chrome, Chrome on Android (Pixel 7) and Safari
  on iPhone (iPhone 15), served by wrangler the way Cloudflare serves it. 41 checks are skipped
  by design, in browsers where they'd repeat desktop's or can't run (Paste and Copy on iPhone).
  - Every code made is read back (the sticker, the PNG and the SVG) with the tests' own copy of
    jsQR and compared with what was typed, emoji and other languages included.
  - Each mistake leaves what was typed as it was; a fix is applied only by a tap.
  - With Cloudflare's real counter script switched on, every request is read while the whole page
    is used, and the counter's report after use is required and read: nothing typed and no part of
    a chosen image leaves. Storage and cookies are checked. A copy at another address sends
    nothing. The page works offline.
  - 13 language pages load cleanly with the exact security policy, fit the screen from 360 px,
    have no serious accessibility problems (axe), and every link leads somewhere.
  - Also: the HTML validator, a wrangler dry run, `tools/pages.py --check`, and the ledger checker.
- After the deploy (run [38098397743](https://github.com/honestrobin/qr/actions/runs/38098397743),
  which ran the checks again first), the live address: every language's page answers, the 404 page
  works, `README.md`, `words/` and `tools/` aren't served, plain http:// moves to https://, the
  security headers are the ones in `_headers`, no cookie is set, and Cloudflare's counter is the
  one the tests run.
- A second agent translated every string in the 12 other languages back to English. Its fixes are
  in the release.
- The promise reviewer read the change against the Robin's Code and the ledger. Its findings were
  fixed before the release: a copy of QR anywhere else sends us nothing;
  the privacy tests got stricter; a failed read says "Doesn't scan"; the ledger's words came down
  to what the code does.
- CI found two real bugs on the way, both fixed: the code was hidden under the robin, and jsQR
  can't read a light code on a dark background (the page now reads its negative).

## What nobody checked

- Nobody has scanned a printed code with a real phone. The page's check is a decoder (jsQR), not
  a phone camera. The maintainer does this first, after release.
- No person has used the page in a browser yet. An agent looked at screenshots from CI and from
  a headless Chrome on the Pi.
- Translations were made and checked by AI only. The maintainer reads Croatian; nobody has read
  the other eleven.
- Cloudflare's counter was seen on the live pages (automatic setup adds it), but nobody has looked
  at QR's visits in Web Analytics yet.
- Copy to the clipboard was tested in desktop Chrome only, and Save or share wasn't tested (no test
  browser offers it).
- Older browsers and Firefox weren't tested.
- The counter's script couldn't be read on the Pi (its network blocks Cloudflare's analytics
  addresses); only CI ran it.
