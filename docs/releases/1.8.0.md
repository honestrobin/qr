# QR 1.8.0, 15 October 2026

## What changed

- **Six questions under the tool,** in all 13 languages, below everything you use: does the code
  expire, how small can I print it, PNG or SVG, can I change the link later, do you see what I
  type, and how is it free. The answer about what you type links to the page's source code on
  GitHub. A dashed line, like the sticker's cut line, sets them apart from the tool.
- **A preview card** for each language (`public/assets/cards/`, 1200 × 630), which chats and social
  media show for a shared link: the headline, and the sticker with a real code that opens that
  language's page. `tools/cards.py` draws them and reads each code back before keeping it.
- **Titles and descriptions for search results** use the words people search with in each
  language, taken from Google's suggestions in that language's main country on 15 October. The
  headline on the page is unchanged. Each description stays under 160 characters, so it isn't cut
  off.
- **Structured data** tells search engines the page is a free web app (schema.org
  `WebApplication`), in each language. There's no FAQ markup: Google shows FAQ results only for
  government and health sites.
- "Honest Robin" at the top of the page keeps its English capitals in every language. In Turkish
  it read "HONEST ROBİN".

## Promises this release touches

None changes. The answers repeat what QR already promises: a code that's yours to keep, that we
never see what you type, what we count, that the code is open source, and that QR is free. Two
answers say a little more than the ledger's words, and both follow from the code holding the link
itself: it doesn't depend on us, and we can't switch it off.

## What the maintainer read

He said yes to the plan for getting QR found, and this is its first step. He hasn't read these
words or seen the cards.

## What agents checked

- **The searched words** came from Google's suggestions, read from the maintainer's Raspberry Pi
  for each language's main country, for "QR code generator", "free QR code" and their own words
  ("qr code erstellen", "qr kod oluşturma", "QRコード作成").
- **The translations:** written by Claude, then checked by three more agents, each translating
  four languages back into English and comparing them with the English. They found grammar
  slips, phrases copied too literally from English, and two titles (Polish and Indonesian) that
  read as "free forever", which isn't a promise QR makes. Their fixes went in, except one that
  its checker wasn't sure of. Italian needed none.
- **The cards:** `tools/cards.py` read each card's code back with jsQR, and each opens its own
  language's page. Looked at all 13.
- **The page,** in Chromium on the Pi: English at 1280 and 390 pixels wide, Japanese at 1280,
  German, and Turkish's top line.
- **A new test** fails if any language loses its title, description, card, structured data or
  questions, or if a card isn't served at the size its tags say.
- **The promise reviewer** read the change against the ledger. Nothing breaks a promise, and
  nothing new sends data anywhere. On its advice, the answer about what you type says plainly that
  nothing typed is sent anywhere; the answer about changing the link says we can't switch the code
  off, not that nobody can, since whoever runs the link can; the German title lost "dauerhaft",
  which could read as "free for good"; and a widened ledger row was put back, since a promise's
  words wait for the maintainer.

## What nobody checked

- A real phone, and how each chat app or social network shows the card.
- Google's own test for structured data.
- Whether the new titles bring more people from search: Search Console will tell, in weeks.
