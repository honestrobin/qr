# QR 1.5.1, 11 October 2026

## What changed

After his audit of 1.5.0, the maintainer asked for plainer, more direct words and picked them
himself. This release is those words, in all 13 languages.

- **The line under the headline** says what the code does: "Free. The code opens your link
  directly, not through us, so it works for as long as your link does. We never see what you
  type." It was "Free, and nothing of ours sits between the code and your link. What you type
  stays on this page." Search engines get the same words.
- **The robin says hello in a lighter way:** "I'm the robin. I'm here to lighten up your day." It
  was "I'm the robin. I check every square."
- **The robin speaks for the code only once the check passes:** "I checked all 625 squares: phones
  can read this code." Until the check says "Scans fine", and for a code that scans only on a
  light surface, it keeps its hello. Before, "This code has 625 squares. I checked every one."
  showed as soon as the code was drawn.
- **The note on images** says what happens to yours: "Your image is never uploaded. We'll check
  that it still scans." It was "Your image stays on this page. The code makes room for it."
- **On a small phone the field stays put.** In Japanese, since 1.5.0, a robin line of four lines
  pushed the field down when the line changed. Every language's lines now fit in three lines at
  360 px wide, and a test checks it.

## Promises this release touches

| Promise | How | Ledger |
|---|---|---|
| We never see what you type | Reworded from "What you type stays on this page", on the page, in the README and in the ledger. The code and its two guards are unchanged | Tested |
| A code that's yours to keep | The page and the README say "opens your link directly, not through us"; the ledger row says it since pull request #22 | Tested |
| Your own image stays on this page | The page now says "never uploaded", which the row already said | Tested |
| One thing is kept on your device | Its guard, the robin's test, changed (below) | Tested |
| Where our words are ahead of the code | The robin's new line is listed there with what it leaves out: the check isn't a phone, the size phones need is in the line under the code, and the squares under an image are counted too | |

**Guards changed:**

- `tests/qr.spec.js::the robin says who it is and counts each code's squares, and stays` has the
  new words, and now also checks that the robin's line waits for the check: stricter.
- `tests/qr.spec.js::a see-through background: scans on a light surface, and the PNG is
  see-through` now also checks that the robin keeps its hello: stricter.
- `tests/privacy.spec.js`: only its first comment changed, to the new words.
- New: `tests/languages.spec.js::on a small phone, the <language> robin's line never moves the
  field`, in all 13 languages.
- **A test that guards no promise was weaker than its record said.** 1.5.0's record said pull
  request #18 made the redraw timing test steady "without raising the limit". The limit stayed,
  but the test timed less: it kept each length's fastest of three draws, and the page reuses the
  code it just made when the text is the same, so the second and third draws skipped encoding.
  Pull request #22 has every timed draw encode again.

## What the maintainer read

He picked the new lines himself, in the other agent's session, after his audit of 1.5.0. In this
session he was shown every changed English line, old and new, and a screenshot of the page on a
phone, and gave his go to deploy all of it. He didn't say whether he read anything more,
such as the translations or the code. His test of the live page comes after this record.

## What agents checked

- **The checks** on pull request #21's last commit (`222b0b4`; run
  [38162751560](https://github.com/honestrobin/qr/actions/runs/38162751560)): 249 passed in
  desktop Chrome, Chrome on a Pixel 7 and Safari on an iPhone 15, axe's accessibility scan
  included; 87 skipped by design; none flaky.
- **A second agent translated the 12 other languages back to English** before the merge. It
  flagged four image notes (Spanish, French, Italian, Japanese) that read like "we'll make sure it
  scans", or in Japanese hinted that we receive the image; a German line with "it" and no noun;
  and an Indonesian line that began with a number. All were fixed before the merge.
- **On the Raspberry Pi:** the robin's line and the field measured in headless Chromium at 360,
  390 and 412 px wide with four lengths of link, in every language; screenshots of the phone
  page; `tools/pages.py --check`; `node --check`; the ledger checker.
- **A second agent's promise review** of `2883518`, after the merge: no broken promise, and no
  ledger guard weaker. It found what pull request #22 fixes: the ledger's "yours to keep" row
  still had the old words, the note on the robin's line left out the size limit and the squares
  under an image, and the redraw test (above). It read the translations for meaning: none says
  more than the English, though Croatian and Polish say "each of the 625 squares", Italian says
  phones "read it" rather than "can read it", and Japanese leaves out phones.
- **The deploy** (run [38170993411](https://github.com/honestrobin/qr/actions/runs/38170993411),
  main `2883518`): the checks again, 249 passed, 87 skipped, none flaky. Both agents started a
  deploy of the same commit two seconds apart; the second was cancelled before it ran.
- **Live, after the deploy,** checked by both agents: the page loads `qr.js?v=23bc6fba1b`, byte
  for byte the file on main; the new hello is on all 13 pages and the robin's new line in the
  English page; `/hr/`, `/es/` and `/ja/` answer; a missing page gives 404; `/count` refuses a
  GET (405), a count not on the list (400) and an oversized one (413).

## What nobody checked

- A real phone: the maintainer's test comes next.
- The translations by a native reader. The back-translation and the review are agents'.
- That an image which breaks the code says "Doesn't scan with this image": no test.
- The robin's line for a code with swapped colours, and from one good code to the next: the code
  was read, not tested.
- Whether phones read a printed code at the lowest contrast the check calls fine (3:1).
- Small phones at widths other than 360 px, in tests; 390 and 412 were measured once, by hand.
- Firefox, Samsung Internet, and Safari older than the iPhone 15's.
