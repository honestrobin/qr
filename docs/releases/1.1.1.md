# QR 1.1.1, 11 October 2026

## What changed

- Tapping the robin made it jump sideways, because the robin and its line were centred together.
  It now stands at the left of its own row.
- The robin, and the buttons below it, shifted a few pixels when the first code came, when its
  line grew and when the check answered. The row keeps room for the line and the answer.
- The robin and its hello appeared only after the page's script ran, and pushed the buttons
  down. They're in the page from the first paint.
- On a phone, the code dropped by up to 40 px when "This code opens …" appeared. Room for three
  lines is kept now; a suggested fix with a button still needs more and moves it.

## Promises this release touches

None. The robin's test gained a check that a tap, a code and the check's answer move neither the
robin nor the buttons.

## What the maintainer read

He reported the jump after using 1.1.0 (tapping the robin moved the page), asked for a review of
the page, and gave his go.

## What agents checked

- The robin's place, measured in Chromium at 1440 and 390 px wide after each step: load, a tap,
  a code, the check's answer, a longer code, a suggested fix, an empty field.
- CI on pull request #9 (its last commit, `d1e37f6`; on main as `612ad94`, which was deployed;
  run [38126469880](https://github.com/honestrobin/qr/actions/runs/38126469880)): 214 passed,
  none failed or flaky. An earlier run failed on the phones because the new check measured the
  robin in the window, which a tap scrolls; it now measures it on the page.
- After the deploy (run [38126741434](https://github.com/honestrobin/qr/actions/runs/38126741434)):
  `/`, `/hr/`, `/ja/` and `/sitemap.xml` answer, a missing page gives 404, and the page has the
  robin's hello in its HTML. For about a minute Cloudflare still served the old stylesheet with the
  new page; then the new one.
- A look-and-feel review of the whole page, by a second agent, found more to fix; those wait for
  the maintainer's choice and aren't in this release.

## What nobody checked

- Two moves are left as they were: the line offering another language ("This page is also in
  English.") appears after the page loads and pushes it down once, and on a phone the Copy or
