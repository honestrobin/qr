# Security

Please report a security problem privately, to **security@honestrobin.com**, or with GitHub's
"Report a vulnerability" button on this repository's Security tab. Please don't open a public
issue. We answer within three working days, and keep you updated until it's fixed.

Include the steps to reproduce it and the impact you expect. We credit you in the release record,
unless you'd rather we didn't.

## In scope

The page at qr.honestrobin.com, its server code (`worker/`), and this repository. Above all,
anything that lets what someone types, or the picture they choose, leave their browser.

Fixes go into the live page and the latest commit on `main`.
